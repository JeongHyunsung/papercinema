# B-Flex: narrated research film (V5, final audit)

A 119-second, 4K60, narrated motion-graphics film introducing *B-Flex: Exploration of Broader Flip-Flop Design Space Based on FSM Exhaustive Search* (DAC 2026, doi:10.1145/3770743.3804333).

Everything is generated by code. The graphs, the search tree, the δ table, the SeGen-20 counterexample and the FF1 replay come from a re-implementation of the paper's method; plotted numbers are typed from the paper's tables. v4 adds:

- a white visual identity;
- an English narration, word-aligned;
- a narration-first re-edit;
- a ducked, loudness-controlled mix;
- SRT subtitles.

V5 adds a paper-grounded scientific audit and narration polish: see `docs/V5_SCIENTIFIC_VERIFICATION.md`, `docs/V5_LANGUAGE_LOG.md` and `docs/V5_TRANSCRIPT.md`.

## Contents

```
src/audio4.py              Score + SFX (procedural), narration placement, ducking, -16 LUFS / -1.2 dBTP master, stems
src/subtitles.py           SRT from word timings
src/audit.py, readability_table.py   Readability audit (time each string is legible)
src/timing_sheet.py        Writes docs/TIMING_SHEET_V4.md
src/bflex_model.py, scene_data.py    Re-implementation of B-Flex; builds data/scene_data.json

narration/srt_check.py     QA: every subtitle cue vs ASR of the delivered film's audio
src/subtitles.py           (V5) cues timed by spoken-word count
docs/                      Script, timing sheet, casting, accuracy checklist, revision log, QA reviews, v3 verification
```

## Reproduce

Requirements:

- Python 3.10+.
- `pip install pycairo numpy scipy pillow soundfile librosa pyloudnorm kokoro-onnx sherpa-onnx`
- ffmpeg with libx264.
- The fonts Inter, Inter Display and JetBrains Mono (OFL).

Model files (not included):

- Kokoro: `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the GitHub release `thewh1teagle/kokoro-onnx` `model-files-v1.0`, placed in `$KOKORO_DIR`.
- ASR: `sherpa-onnx-zipformer-en-2023-06-26` from the `k2-fsa/sherpa-onnx` release `asr-models`.

```bash
cd narration
python3 narrate.py && python3 align.py      # voice -> lines/*.wav, lines.json, words.json
cd ../src
python3 edl.py                              # checks clip placement (no overlaps), prints runtime
python3 audio4.py                           # stems + mix -> out/audio_v4/
python3 subtitles.py                        # SRT
python3 audit.py film ../docs/audit_v4.json # readability audit
python3 render.py stills --w 1280 --times 37.5 65.5 102.5
cd .. && JOBS=4 ./render_chunks_v5.sh && ./assemble_v5.sh
```

## Editing

- **Change the words.**
  1. Edit `narration/script.py`.
  2. Re-run `narrate.py` and `align.py`.
  3. Run `src/edl.py`, which reports any overlap.
  4. Lengthen the segment before the overlapping clip in `SEGMENTS`.
- **Use a different voice, including ElevenLabs.** Replace `narration/lines/Lxx.wav`, then re-run from `align.py`.
- **Retime the picture.** `SEGMENTS` in `src/edl.py`: each row is (animation time reached, film seconds it takes). Keep the race segment at slope 1.
- **Change the look.** Palette at the top of `src/engine.py`.
